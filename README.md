# 🦅 Avian Biodiversity & Bird Species Analysis Dashboard

An interactive data analysis platform and Streamlit dashboard evaluating bird species observations across **Forest** and **Grassland** habitats across 11 national park administrative units.

---

## 📌 Project Overview
This project processes and analyzes **17,000+ bird observation records** to extract ecological insights, monitor at-risk species on the **PIF Watchlist**, and assess environmental impacts like temperature and human disturbance.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 3.10+
* **Data Processing:** Pandas, NumPy
* **Database Management:** SQLite, SQLAlchemy
* **Data Visualization:** Plotly Express, Seaborn, Matplotlib
* **Web App Framework:** Streamlit
* **Deployment:** Streamlit Cloud

---

## 🚀 Key Features
* **Interactive Dashboard:** Filter sightings by Administrative Unit, Habitat Type, Year Range, and At-Risk Watchlist status.
* **Spatial & Species Diversity:** Dynamic bar and pie charts identifying top species counts and habitat distribution.
* **Temporal Patterns:** Analysis of monthly seasonality and observer reporting volumes.
* **Environmental Analysis:** Multi-variable correlation analyzing temperature distributions and human disturbance impacts.
* **Conservation Insights:** Direct tracking of threatened species listed under the *Partners in Flight (PIF)* Watchlist.
